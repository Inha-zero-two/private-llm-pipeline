# web — 채팅 화면

React + Vite (TypeScript). 상세 설계서 9장의 화면 세 개(메인 채팅, 추가 개인정보 공개 요청, 공개 허용 설정)를 만든다.

## 실행

```bash
cd web
npm install
npm run dev        # http://localhost:5173
```

| 명령             | 내용                                      |
| ---------------- | ----------------------------------------- |
| `npm run dev`    | 개발 서버                                 |
| `npm run build`  | 타입 검사 + 빌드                          |
| `npm run lint`   | oxlint                                    |
| `npm run format` | Prettier로 정리 (`format:check`는 검사만) |

## 데모 동작

화면 껍데기만 있고 백엔드와 연결하지 않는다. 질문을 보내면 브라우저 안 데모(`src/demo`)가 설계서 흐름(①~⑧)대로 진행 단계와 답변을 채운다. 데이터는 메모리에만 있어 새로고침하면 사라진다.

### 데모 시나리오

질문에 아래 낱말을 넣으면 해당 상황을 볼 수 있다.

| 질문에 넣을 것                                                     | 상황                                     |
| ------------------------------------------------------------------ | ---------------------------------------- |
| 나이(`27살`), 전화번호, 회사 · 학교 이름(`삼성전자`, `인하대학교`) | 추가 공개 동의 요청                      |
| `동의`                                                             | 위 항목이 없어도 예시 항목으로 동의 요청 |
| `오류`                                                             | 실행 오류                                |
| `오프라인`                                                         | 외부 모델 연결 불가                      |
| `상한`                                                             | 질문 상한 도달                           |

공개 허용 설정에서 허용한 종류(예: "나이는 공개해도 돼")는 동의를 묻지 않는다.

## 구조

```
src/
  types.ts          화면에서 쓰는 자료형
  demo/             데모 실행 · 시나리오 · 설정문 해석 (백엔드를 붙일 때 바꿀 부분)
  components/       사이드바, 대화, 입력창, 동의 창, 설정 창 등
  App.tsx           채팅 목록 · 실행 상태를 들고 화면을 조립한다
```

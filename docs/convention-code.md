# 코드 컨벤션

## 이름 규칙

⏳ 미정

- 파일 · 함수 · 변수 · 클래스 이름을 어떤 형식으로 쓸지
- 상세 설계서의 함수 이름(`decideContext` 등)을 코드에서 어떻게 옮길지

## 폴더 구조

⏳ 미정

- 상세 설계서 2.2의 모듈을 어느 폴더 · 파일에 둘지
- 테스트 파일 위치와 이름

## 모듈 사이 데이터 형식

⏳ 미정

- 함수 인자 · 반환값을 dict로 넘길지, 정해진 클래스로 넘길지
- 함수 정의에 타입 힌트를 필수로 둘지

## 로그 · 개인정보

⏳ 미정

- 로그에 무엇을 남겨도 되는지 (사용자 입력 · 프롬프트 원문 포함 여부)
- 테스트 데이터에 쓸 수 있는 데이터

## 설정 · 비밀값 · 패키지

⏳ 미정

- API 키 · 모델 경로 등 설정값을 어디에 둘지
- 패키지 추가 방법과 lock 파일 커밋 여부
